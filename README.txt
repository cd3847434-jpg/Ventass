# Comercial Talita Cumi

Aplicación web/PWA de registro de ventas para Kevin Antonio Rodriguez.

## Archivos
- index.html: estructura de la aplicación.
- styles.css: diseño responsive.
- app.js: ventas, productos, estadísticas, foto de perfil y almacenamiento local.
- manifest.json: permite instalarla como aplicación.
- sw.js: permite funcionamiento PWA/caché.
- logo-talita-cumi.jpeg: logo proporcionado.

## Datos
Los productos, ventas y foto de perfil se guardan en localStorage del navegador.

## Instalar en Android
La página debe estar publicada por HTTPS (GitHub Pages, Netlify, Vercel, etc.).
En Chrome: abrir la web -> menú ⋮ -> "Instalar aplicación" o "Agregar a pantalla de inicio".

Nota: si se borra la información del navegador, los datos locales pueden perderse. Para varios teléfonos o respaldo en la nube hay que conectar una base de datos/backend.
